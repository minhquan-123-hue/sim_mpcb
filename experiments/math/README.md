# Math Experiments

Small, isolated exercises used to understand mathematical relationships before connecting them to a larger simulation.

- `height.py`: evaluates a simple function of time.
- `differential.py`: compares a function at nearby input values to explore how output changes.
- `power_integral.py`: integrates a time-varying power function over an interval.
- `weighted_sum.py`: practices weighted sums.

When an experiment becomes part of a real-world system, move or adapt it into the relevant folder under `systems/` and document its assumptions and units.
